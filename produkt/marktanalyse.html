    Marktanalyse — Konkurrenten und ihre Modelle¶

    Snapshot, kein Beschluss

    Stand: 2026-05. Diese Seite ist eine Momentaufnahme des Markts und eine Diskussions-Grundlage — keine getroffene Entscheidung. Pricing, Positionierung und Strategie der genannten Anbieter ändern sich monatlich. Behandele Zahlen als groben Stand, nicht als heute-noch- gültiges Angebot. Wer diese Seite aktualisiert: neuen Snapshot-Stempel setzen und ggf. eine ältere Version archivieren.

    Agentry sitzt in einem schnell wachsenden Markt für AI-gestützte Software- Entwicklungs-Tools. Diese Seite sortiert die heute relevanten Anbieter in drei Gruppen — nach Nähe zu Agentrys Positionierung (Trigger-basiertes Issue → PR mit Daemon-Modell).

    Gruppe A — Direkte Konkurrenten (Issue → PR autonom)¶

    Devin (Cognition Labs)¶

    Eigenschaft Wert
    Was Vollautonomer „AI Software Engineer", web-basierte Konsole
    Deployment Reines SaaS
    Pricing Anfangs $500/Monat Flatrate, später verbrauchsbasiert (ACU-„Compute Units" ~$2,25 pro Einheit), Enterprise-Tier separat
    Modell-Mix SaaS + Hybrid-Pricing

    Relevanz für Agentry: Devin ist der „Markt-Bildner" — wer Devin kennt, versteht sofort, was Agentry tut. Devin ist closed-source und nimmt Kunden-Code in die Cloud — genau die Angst-Punkte, an denen Agentry mit On-Prem punkten kann.

    Cosine (Genie)¶

    Eigenschaft Wert
    Was AI-Engineer, lange SWE-bench-Spitze
    Deployment SaaS, Enterprise-Self-Hosting auf Anfrage
    Pricing Subscription pro Seat (~$40–80/Monat), Enterprise-Custom
    Modell-Mix SaaS-First, On-Prem als Enterprise-Tür

    Relevanz: Ähnliche Positionierung wie Devin, akademischer Touch (Benchmark-Leadership).

    Factory.ai (Droids)¶

    Eigenschaft Wert
    Was Mehrere spezialisierte „Droids" (Code, Review, Migration), Slack-/Linear-/GitHub-integriert
    Deployment SaaS, Enterprise mit VPC-Deployment
    Pricing Enterprise-Sales, keine öffentlichen Preise
    Modell-Mix SaaS + Hybrid (Control-Plane in Factory-Cloud, Worker im Kunden-VPC)

    Relevanz: Die Variante, gegen die Agentry „im selben Raum" antritt — beide gehen Pipeline-getrieben, beide trigger-basiert. Factory hat aber einen vollständigen Sales-Apparat.

    Sweep AI¶

    Eigenschaft Wert
    Was Der OG für Issue → PR
    Deployment Erst OSS self-hostable, dann SaaS-Pivot, mittlerweile praktisch aufgegeben
    Pricing Free + paid Tiers ($120/Monat pro Repo)

    Relevanz — wichtigste Warnung. Sweep hat genau das gebaut, was Agentry baut, und ist gescheitert — primär weil GitHub Copilot Workspace + Claude Code direkt dieselbe Funktion gratis/günstig bauten. Lessons: reine SaaS- Variante hat schwer gegen die Plattformen gewonnen. Open-Core + Enterprise- On-Prem ist plausibler.

    GitHub Copilot Coding Agent¶

    Eigenschaft Wert
    Was GitHub-eigener Agent, übernimmt @copilot-Mentions auf Issue/PR
    Deployment Embedded in GitHub.com (SaaS), GHES für Enterprise
    Pricing In Copilot-Subscription enthalten ($10/$19/$39 pro User/Monat) plus Premium-Request-Verbrauch
    Modell-Mix Subscription + Verbrauch, bundled mit Plattform

    Relevanz — gefährlichster Konkurrent. Wenn man auf GitHub ist, ist der schon da. Agentrys Antwort muss sein: Multi-Provider (GitLab, künftig Jira), Multi-Backend (Claude + Codex + …), Self-Hosted (sensible Codebases), Trigger-Customization (Sandbox-Routing pro Label etc.).

    Gruppe B — Open-Source / Self-Hosted (näher am Agentry-Geist)¶

    OpenHands (ehem. OpenDevin)¶

    Eigenschaft Wert
    Was Open-Source Devin-Klon, vollautonomer Agent
    Deployment Self-Hosted (Docker), All-Hands-AI bietet Cloud-Version
    Pricing OSS MIT, Cloud verbrauchsbasiert
    Modell-Mix Klassisches Open-Core: OSS-Engine + kommerzielle Cloud

    Relevanz: Wahrscheinlich am-nächsten-an-Agentry positioniert. Beide setzen auf Self-Hosted-First. OpenHands ist Container-First/Web-UI-zentriert, Agentry ist Daemon/Ticket-First — anderer Use-Mode, gleicher Markt.

    Aider¶

    Eigenschaft Wert
    Was Terminal-basiertes AI-Pair-Programming, kein autonomer Agent (interaktiv)
    Deployment Lokal (Python-CLI), BYOK (Bring Your Own Key)
    Pricing Komplett gratis, Apache-2.0

    Relevanz: Anderes Segment (interaktiv, nicht trigger-getrieben), aber Aider beweist: BYOK-Modell akzeptieren Devs. Agentry kann das gleiche Argument fahren („du zahlst Claude/Codex direkt, wir nehmen nur Lizenz für die Pipeline").

    Claude Code (Anthropic) — Backend, kein direkter Konkurrent¶

    Eigenschaft Wert
    Was Anthropics CLI, ist Agentrys Default-Backend
    Pricing API-Verbrauch

    Strategisches Risiko: Wenn Anthropic einen „Daemon-Modus" baut, hat Agentry ein Problem. Strategische Chance: Solange Agentry provider- agnostisch bleibt (Claude + Codex + …), ist es gegen dieses Risiko abgesichert.

    Gruppe C — Adjacent (anderes Segment, gleicher Markt-Pitch)¶

    Tool Modell Pricing Relevanz für Agentry
    Cursor SaaS-IDE $20/Monat Pro, Business-Tier Andere Use-Mode (IDE), aber zeigt: $20-Subscription funktioniert.
    Tabnine SaaS + On-Prem (Enterprise) $12 Dev, $39 Enterprise Sehr instruktiv: Tabnine hat den On-Prem-Enterprise-Pfad früh ernst genommen, weil Banken/Behörden Code nicht in fremde Clouds geben. Genau Agentrys Argument.
    Continue.dev Open-Source + SaaS-Hub OSS + Team-Pricing Open-Core-Beispiel: OSS-Extension + kommerzieller Team-Hub.
    CodeRabbit SaaS, On-Prem-Enterprise $24/Dev/Monat Macht AI-Code-Review, nicht Generation — komplementär. Könnte Partner statt Konkurrent sein.
    Replit Agent SaaS (gebunden an Replit-Plattform) In Replit-Subscription Andere Zielgruppe (Hobbyisten, Cloud-IDE).

    Beobachtungen¶

    1. Reines SaaS verlieren die Kleinen. Sweep ist das Mahnmal. Devin + Cognition haben Mrd.-Bewertung — als Indie/kleines Team kann man gegen GitHub & Co. nicht im selben Lane gewinnen.

    2. On-Prem-Self-Hosted ist der ungenutzte Slot. Tabnine hat es vorgemacht, OpenHands ist die OSS-Variante, aber im „polierten, kommerziellen, kuratierte Trigger-Pipeline"-Slot ist Platz. Genau dort sitzt Agentry heute.

    3. BYOK ist akzeptiert. Devs hassen Marken-Lock-in bei AI-Anbietern. Agentry kann sagen: „du zahlst Claude/Codex direkt, wir zählen nichts mit." Echter Vertrauensvorteil ggü. Devin.

    4. Open-Core ist etabliert. GitLab, Sentry, OpenHands, Continue — alle fahren das. Klarer Pfad: Kern offen, Premium = SSO, Audit, Multi-Tenant-Dashboard, GitLab-/Jira-Sources, Support-SLA.

    5. Enterprise-Sales sind langsam. Factory.ai macht das, aber das braucht einen Sales-Apparat. Für ein kleines Team ist Self-Service- Bottom-Up (Devs probieren, kleine Teams kaufen, große Teams fragen IT) realistischer.

    Plausibler Pfad für Agentry (aus dieser Analyse)¶

    • Kern Open-Source (MIT/Apache): Daemon, GitHub-Source, Claude/Codex- Backends, Polling.
    • Kommerzielle Schicht (On-Prem-Lizenz): GitLab/Jira-Sources, SSO, Audit-Logs, Multi-Tenant-Dashboard, Sandbox-Profile, Support-SLA.
    • Pricing: Subscription pro Daemon-Instanz oder pro aktivem Repo (z. B. $99/Monat pro Daemon mit unlimited Repos, oder $19/Repo/Monat).
    • BYOK: Kunde nutzt seinen Claude-/OpenAI-Account. Agentry zählt nur Lizenz.
